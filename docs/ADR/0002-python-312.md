# ADR 0002 — Use Python 3.12

## Status

Accepted

## Context

The project requires fast iteration across AI providers, audio, video, automation, and analytics.

## Decision

Use Python 3.12 as the primary implementation language.

## Consequences

Positive:

- strong ecosystem for AI and media automation
- rapid experimentation
- broad SDK support

Negative:

- requires discipline around typing and project structure

Mitigation:

- mypy
- Pydantic
- pytest
- ruff
- explicit architecture boundaries
